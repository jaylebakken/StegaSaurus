# Saurus Web Alpha Assets

These assets support the alpha web interface. They are intentionally stored
locally so the app can keep a strict same-origin image policy.

## Files

- `nist-oscilloscope-traces.jpg`
  - Source: Wikimedia Commons file `Oscilloscope traces (5941055080).jpg`.
  - Credit: Hamilton/NIST.
  - Licensing note: listed as public domain in the United States as NIST / U.S.
    federal government work. Keep the credit visible when practical.

- `cc0-sound-wave.svg`
  - Source: ClipSafari / GDJ sound wave SVG.
  - Licensing note: listed as CC0 No Rights Reserved and usable for commercial
    purposes.

## Design Use

- Use the NIST oscilloscope photo for analog recording, lab signal, and
  measurement symbolism.
- Use the CC0 waveform as a lightweight texture, divider, or motion cue.
- Do not use either asset to imply measured robustness or standards validation.
